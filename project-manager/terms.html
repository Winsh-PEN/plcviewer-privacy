1. 제공 기능

Project Manager Sync는 프로젝트와 관련 자료의 작성, 보관, 출력 및 선택적 기기 간 동기화를 지원합니다. 제공 기능은 앱 버전과 연결한 저장소에 따라 달라질 수 있습니다.

2. 사용자 자료

사용자가 등록한 자료에 대한 권리는 사용자 또는 원래 권리자에게 있습니다. 사용자는 보관과 공유 권한이 있는 자료를 등록하고, 회사의 보안 규정을 확인해야 합니다. 앱 운영자는 자료를 등록했다는 이유만으로 소유권을 취득하지 않습니다.

3. 계정과 저장소

사용자는 본인이 이용할 수 있는 계정과 저장소를 연결합니다. Google, MYBOX 및 자체 서버의 사용 조건, 용량 제한, 이용 비용과 운영 정책은 해당 제공자의 조건에 따릅니다. 계정 정보와 기기 접근을 보호해 주세요.

4. 백업과 계산 확인

동기화는 별도의 장기 백업을 대신하지 않습니다. 중요한 자료를 정기적으로 내보내고, 삭제 및 서버 정리 전에 사본을 확인해 주세요. 활동비 계산과 출력 결과는 입력값과 선택한 규정·양식에 따르므로 제출 또는 지급 전에 확인해야 합니다.
