PLC Toolkit PC 사용설명서

PLC-Toolkit-PC.exe 하나로 실행합니다. 별도 Python·Excel 설치나 _internal 폴더가 필요 없습니다. 코멘트 CSV·엑셀과 점검 기록을 정리하고 폰과 동기화합니다.

1직접 자동 동기화

  1. PC에서 코멘트 CSV·엑셀을 열고 PC 작업 저장으로 .plctk 파일을 만듭니다.
  2. PC·폰 자동 동기화를 열고 폰에서 접속할 PC 주소를 고릅니다. 같은 Wi-Fi/LAN의 PC 주소나 양쪽에 연결한 Tailscale 주소를 사용하세요. 기본 포트는 8767입니다.
  3. 동기화 시작 → 연결 코드 복사를 누릅니다. 코드는 5분 동안 한 번 사용할 수 있으며, 만료되면 새 연결 코드를 누릅니다.
  4. Android 앱의 PLC 연결 → PC 직접 동기화에서 코드를 붙여넣고 연결합니다. 처음 연결할 때 현재 폰 자료의 보관·교체 안내를 확인하세요.
  5. 두 앱이 열려 있고 PC 동기화가 시작된 동안 코멘트·OK/NG·메모·PDF/사진·IO 스티커 배치가 자동으로 저장·동기화됩니다. 폰 앱이 화면에 열려 있을 때 동기화하며, 휴대폰이 잠기거나 앱이 배경으로 가면 다시 열 때 이어집니다.
  6. PC가 꺼져 있거나 연결이 끊겨도 이미 받은 자료는 각 기기에 저장되어 계속 볼 수 있습니다. 오프라인 변경은 다시 연결하면 합칩니다.
  7. 같은 항목을 양쪽에서 다르게 수정하면 자동으로 덮어쓰지 않습니다. 서로 바뀐 내용 확인에서 PC와 폰·공유 내용을 보고 남길 쪽을 고릅니다. 서로 다른 항목의 변경은 함께 반영합니다.
  • PC에서 행 편집은 선택 1개 저장으로 확정하세요. 입력 중인 문장은 동기화가 지우지 않으며, 확정한 편집은 PC 작업에 자동 저장합니다.
  • 저장된 작업에서 도면을 열거나 배치하면 원본과 배치가 작업에 저장됩니다. 작업 도면 열기로 다시 열 수 있고, 편집 충돌 시 보관된 초안도 이 목록에서 찾을 수 있습니다.
  • 연결이 안 되면 Windows 방화벽에서 PLC Toolkit PC의 TCP 8767 수신을 필요한 LAN/Tailscale 범위에 허용했는지 확인하세요. 포트를 바꿨다면 그 포트를 사용합니다. 이 앱은 방화벽 규칙을 자동 변경하지 않습니다.
  • 인터넷의 별도 서버나 계정은 필요하지 않습니다. 폰이 PC 주소로 접속할 수 있어야 하며, PC와 폰이 서로 다른 네트워크이면 Tailscale 등 연결 경로가 필요합니다.
  • 중지는 PC의 동기화 수신을 닫습니다. 등록 기기 해제는 모든 등록 폰의 접속 권한을 해제하며, 다시 연결할 때 새 코드를 사용합니다. 이미 저장된 자료는 유지됩니다.
  • .plctk 파일과 같은 이름의 .sync 폴더를 함께 보관·백업하세요. 예: 현장A.plctk + 현장A.sync. .sync에는 도면 원본·이전 공유 내용·기기 등록·암호화 연결 키가 있습니다.
  • 기기 등록 정보는 현재 Windows 사용자 계정에 연결되어 있습니다. 다른 PC나 다른 Windows 사용자로 옮길 때는 자료를 수동 파일로 옮겨 새 작업으로 연결하세요. 같은 PC·사용자의 재시작에는 등록이 유지됩니다.
  • PLC 조회 연결과 자료 동기화 연결은 별개입니다. 동기화가 PLC 출력이나 쓰기 잠금을 변경하지 않습니다.

2수동 파일 전달: PC → 모바일 → PC

  1. 코멘트 CSV·엑셀 열기: UTF-8, UTF-16, CP949 CSV·탭 텍스트 또는 .xlsx를 읽습니다. 엑셀은 가져올 시트를 선택하고 주소/디바이스·내용/코멘트 머리글을 사용합니다. 엑셀에서 복사한 두 열은 목록을 누르고 Ctrl+V로 넣을 수 있습니다.
  2. 행을 선택하고 코멘트·판정·메모를 고친 뒤 선택 1개 저장을 누릅니다. Ctrl/Shift로 여러 행을 선택해 판정만 일괄 적용할 수도 있습니다.
  3. 모바일용 코멘트 저장으로 CSV를 저장하고 USB·공유폴더·메신저로 폰에 옮깁니다. 모바일 앱에서 코멘트 파일을 여세요.
  4. 모바일에서 점검한 뒤 점검 기록 → 파일 내보내기로 JSON을 저장해 PC로 옮깁니다.
  5. PC에서 같은 코멘트를 열고 모바일 점검 기록 열기를 누릅니다. 판정과 메모가 교체됩니다. IO와 서보 센서 점검 항목을 모두 읽습니다.
  6. 검색 또는 NG/OK/미점검 필터를 걸고 결과 CSV·엑셀 추출을 누릅니다. 화면에 표시된 항목만 내보냅니다. 전체 결과를 뽑으려면 검색을 비우고 판정을 전체로 바꾸세요.
  • PC 작업 저장 .plctk: 코멘트·판정·메모·원래 기록 정보와 도면 목록을 보관합니다. 도면 원본은 같은 이름의 .sync 폴더에 저장합니다.
  • 모바일용 점검 기록 저장 JSON: 모바일 앱의 기록 가져오기에서 열 수 있습니다. 코멘트는 JSON에 없으므로 CSV도 따로 전달하세요.
  • 코멘트 CSV로 보낼 때 줄바꿈은 공백으로 바꿉니다. 모바일의 줄 단위 CSV 읽기와 호환됩니다. PC 작업과 엑셀 보고서에서는 원래 문장을 유지합니다.
  • 결과는 새 파일로 출력합니다. 원래 엑셀 양식의 빈 칸 채우기와 GXW 직접 열기는 아직 포함하지 않았습니다.
  • 아직 .plctk로 저장하지 않은 작업은 자동 저장 대상이 아닙니다. 먼저 PC 작업을 저장하세요.

3도면 열기·IO 스티커 배치

  • 메인 화면에서 도면 IO 배치를 엽니다. PDF 또는 사진을 넣고 IO 목록에서 주소를 고른 뒤 도면의 빈 곳을 클릭하면 스티커가 생깁니다. 주소를 직접 입력해도 됩니다.
  • 스티커를 끌어 이동하고 왼쪽 폭 슬라이더로 크기를 바꿉니다. 휠로 확대·축소, 오른쪽 버튼을 끌어 도면 이동, 맞춤으로 전체 보기로 돌아갑니다.
  • ST 비트 스티커는 지원하지 않습니다. ST 코멘트와 점검 기록은 보관할 수 있습니다.
  • PDF는 페이지별로 스티커를 저장합니다. 최대 256개, 원본은 30MB 이하·PDF 1000쪽 이하입니다.
  • 도면 저장으로 .plcdraw를 저장하고 모바일 PLC 연결 → 도면 IO → PC 도면 가져오기에서 엽니다.
  • 모바일에서 사진/PDF를 직접 열어 스티커를 만들 수도 있습니다. 편집 중 스티커를 터치하면 IO·크기를 바꾸고 끌면 이동합니다.
  • 모바일에서 IO 점검 탭은 상태 조회와 OK/NG 기록, 출력 조작 탭은 스티커 선택 후 별도 ON/OFF 출력 버튼을 제공합니다. 쓰기 잠금을 해제한 경우에만 출력 버튼을 누를 수 있습니다. 회색 — 표시와 끊김 상태에서는 쓰지 않습니다. 읽기 상태는 3초 이상 오래되면 미확인으로 표시합니다.
  • 모바일의 도면 내보내기 파일은 PC의 도면 불러오기로 다시 편집할 수 있습니다.
  • PC의 PLC 연결은 읽기 전용입니다. 도면 화면에 PLC 주소·MC 포트를 넣고 조회 시작을 누르면 현재 페이지의 IO를 실시간 조회합니다. 확대·이동 중에도 조회합니다. 배경은 ON 녹색 / OFF 청색 / 미확인 회색이며, 수신이 오래되거나 끊기면 현재값을 지웁니다.
  • 직접 동기화로 작업에 저장한 도면과 배치를 자동 전달할 수 있습니다. 기존 .plcdraw 파일 전달도 계속 지원합니다.

4스티커 크기·점검 결과

  • 폭은 도면의 0.1~40%로 입력하며 기본은 2%입니다. 높이와 글자도 비례하여 줄어듭니다. 숫자 입력 후 Enter 또는 슬라이더를 사용하세요.
  • 마우스 위치를 기준으로 최대 64배 확대합니다. 스티커를 더블클릭하면 주소·크기 수정 창이 열립니다.
  • 스티커를 선택해 왼쪽 OK / NG / 초기화로 점검합니다. 같은 IO의 스티커와 메인 IO 목록에 함께 반영되며 메모는 유지합니다. PLC 출력은 바꾸지 않습니다.
  • 조회 시작 시 배치 편집이 해제됩니다. 스티커를 선택해 점검하거나 휠/오른쪽 끌기로 도면을 확인하세요. 배치를 바꾸려면 오른쪽 위 배치 편집을 켭니다.
  • PLC ON/OFF 상태와 점검 OK/NG는 별개입니다. 상태는 스티커 배경과 두 번째 줄, 점검은 테두리와 왼쪽 상세 영역에 나타납니다.
  • 직접 동기화에서는 점검 결과와 도면이 함께 전달됩니다. 수동 파일 방식에서 도면 저장은 도면과 IO 배치만 포함하므로 점검 결과를 폰에 옮길 때는 점검 기록 JSON도 전달하세요.
  • 작은 스티커가 든 도면을 폰에서 열 수 없다면 모바일 앱을 최신 버전으로 업데이트하세요.

5도면 저장·불러오기

  • 도면 창 위의 도면 저장(Ctrl+S) / 도면 불러오기(Ctrl+O)로 원본과 IO 배치를 .plcdraw 한 파일에 저장·복원할 수 있습니다. OK/NG·메모를 포함한 전체 작업은 메인 화면의 PC 작업 저장을 사용하세요.

6스티커를 유지한 도면 교체

  • 도면을 연 상태에서 도면만 교체를 누르고 새 PDF·사진을 선택합니다. 기존 IO 주소·위치 비율·크기·페이지 번호와 점검 결과를 유지합니다.
  • 도면 내용·여백·가로세로 비율이 달라지면 실제 대상과 스티커 위치가 어긋날 수 있으니 교체 후 확인하세요.
  • 스티커가 붙어 있는 페이지가 새 파일에 없으면 교체하지 않고 기존 자료를 유지합니다.
  • 교체한 결과는 도면 저장으로 저장할 수 있습니다. PC 작업에 포함된 도면은 기존 자동 저장·직접 동기화에도 반영됩니다.

7스티커 크기 일괄 변경

  • 도면 창의 크기 일괄 변경에서 도면 전체 / 현재 페이지를 선택하고 스티커 폭을 0.1~40%로 입력합니다. 적용하면 대상 스티커가 같은 크기로 바뀝니다.
  • IO 주소·위치·페이지·점검 결과는 유지합니다. 취소하면 바뀌지 않습니다. 바뀐 크기는 도면 저장·직접 동기화에도 반영됩니다.
  • 스티커 표시를 끄면 배치를 유지한 채 도면만 볼 수 있습니다. 숨김 중에도 도면을 확대·축소할 수 있습니다.
  • 코멘트 표시를 켜면 IO 목록의 코멘트를 주소와 함께 확인할 수 있습니다. 긴 내용은 스티커에 마우스를 올리거나 선택해 확인하세요. 표시 옵션은 다른 기기의 배치를 바꾸지 않습니다.
