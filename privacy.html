요약

이 앱은 개인정보를 수집하지 않습니다. 서버로 보내는 데이터가 없고, 광고나 분석 도구도

넣지 않았습니다. 앱이 통신하는 상대는 사용자가 직접 입력한 PLC 뿐입니다.

수집하지 않는 것

  • 이름, 전화번호, 이메일, 주소 등 신원 정보
  • 위치 정보
  • 연락처, 사진, 통화 기록, 문자
  • 광고 식별자, 기기 식별자
  • 앱 사용 기록, 분석 데이터, 오류 보고

계정을 만들 필요가 없고, 로그인 기능 자체가 없습니다.

기기 안에만 저장되는 것

아래 항목은 앱의 전용 저장 공간에만 저장되며 기기 밖으로 나가지 않습니다.

디바이스 코멘트 파일은 사용자가 시스템 파일 선택 창에서 고른 파일을 읽기만 하며,

읽은 내용은 앱이 실행되는 동안 메모리에만 두고 따로 저장하거나 전송하지 않습니다.

CSV 내보내기는 사용자가 저장 위치를 직접 지정할 때만 동작하며, 지정한 위치에만 씁니다.

네트워크 사용

이 앱은 산업용 PLC(미쓰비시 MELSEC 계열)와 통신하는 도구입니다. 네트워크는 다음 두 가지에만

사용합니다.

PLC 접속 — 사용자가 입력한 IP 주소와 포트로 접속해 MC 프로토콜로 디바이스 값을

읽고 씁니다. 이 통신은 사용자가 지정한 상대와만 이루어집니다.

PLC 검색 — 사용자가 검색 버튼을 눌렀을 때만, 기기가 접속해 있는 로컬 네트워크 대역의

주소에 사용자가 설정한 포트로 접속을 시도해 PLC 를 찾습니다. 산업 현장에서 PLC 의 IP 를

모를 때 쓰는 기능이며, 찾은 결과는 화면에 보여 줄 뿐 어디에도 저장하거나 전송하지 않습니다.

이 동작은 사용자가 직접 실행할 때만 일어납니다.

앱은 개발자나 제3자의 서버에 접속하지 않습니다.

앱에는 광고 SDK, 분석 SDK, 크래시 리포팅 도구가 포함되어 있지 않습니다.

데이터 삭제

  • 점검 기록만 지우려면 앱 안에서 관련 기록을 지우면 됩니다.
  • 저장된 모든 내용을 지우려면 기기 설정에서 앱 데이터를 삭제하거나 앱을 제거하면 됩니다.
  • 앱을 제거하면 앱이 저장한 내용은 기기에서 모두 사라집니다.
