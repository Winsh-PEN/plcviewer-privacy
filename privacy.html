개인정보처리방침 — PLC 툴박스

최종 수정일: 2026년 9월 12일

요약

이 앱은 개인정보를 자동으로 수집하거나 개발자 서버로 전송하지 않습니다. 분석 도구나 오류 보고 SDK도 넣지 않았습니다. 사용자가 「기능 요청 · 버그 신고」에서 메일 앱을 열어 직접 문의를 보내는 경우에만 개발자가 이메일 주소와 문의 내용을 받습니다.

다만 앱 무료 제공을 위해 구글 애드몹(Google AdMob) 배너 광고를 메인 화면 아래에 표시합니다. 광고 표시 과정에서 구글이 광고 식별자 등 일부 정보를 수집할 수 있습니다. 자세한 내용은 아래 「광고」 절에 적었습니다.

개발자가 수집하지 않는 것

  • 이름, 전화번호, 이메일, 주소 등 신원 정보
  • 위치 정보
  • 연락처, 사진, 통화 기록, 문자
  • 앱 사용 기록, 분석 데이터, 오류 보고
  • 사용자가 연 PLC 파일과 그 내용
  • 사용자가 입력한 PLC 접속 정보와 점검 기록

계정을 만들 필요가 없고, 로그인 기능 자체가 없습니다.

기기 안에만 저장되는 것

아래 항목은 앱의 전용 저장 공간에만 저장되며 기기 밖으로 나가지 않습니다.

항목내용
PLC 접속 설정사용자가 입력한 IP 주소, 포트, 네트워크 번호, PC 번호
점검 기록사용자가 입력한 정상 체크와 메모
보기 설정한 번에 볼 개수, 값 표시 형식 등

디바이스 코멘트 파일과 프로그램 파일은 사용자가 시스템 파일 선택 창에서 고른 파일을 읽기만 하며, 읽은 내용은 앱이 실행되는 동안 메모리에만 두고 따로 저장하거나 전송하지 않습니다. 설비 도면과 회로는 영업 비밀에 해당하는 경우가 많아 특히 조심해서 다룹니다.

CSV 내보내기는 사용자가 저장 위치를 직접 지정할 때만 동작하며, 지정한 위치에만 씁니다.

광고

이 앱은 구글이 제공하는 AdMob SDK 로 메인 화면 아래에 배너 광고를 표시합니다. 광고는 메인 화면에만 있으며, 래더 보기와 IO 체크 화면에는 표시하지 않습니다.

광고를 표시하고 부정 클릭을 걸러내기 위해 구글은 다음과 같은 정보를 수집·처리할 수 있습니다.

  • 광고 식별자(Android 광고 ID)
  • 기기 종류, 운영체제 버전, 화면 크기, 언어 및 국가 같은 일반적인 기기 정보
  • IP 주소에서 추정한 대략적인 위치(도시 수준)
  • 광고를 보거나 누른 기록

개발자는 이 정보를 받지 않으며 볼 수도 없습니다. 개발자에게 전달되는 것은 광고 수익 합계 같은 통계뿐이며, 개인을 알아볼 수 있는 정보는 포함되지 않습니다.

구글이 이 정보를 어떻게 다루는지는 아래에서 확인할 수 있습니다.

  • 구글 개인정보처리방침: https://policies.google.com/privacy
  • 구글 파트너 사이트·앱 데이터 사용 방침: https://policies.google.com/technologies/partner-sites

맞춤 광고를 끄는 방법 — 안드로이드 기기 설정 → 개인정보 보호 → 광고 에서 광고 ID 를 재설정하거나 삭제할 수 있습니다. 광고 ID 를 삭제하면 맞춤 광고가 표시되지 않습니다.

유럽 경제 지역, 영국, 스위스 사용자에게는 광고 표시 전에 구글의 동의 화면이 나타나며, 거기서 동의 여부를 직접 고를 수 있습니다.

네트워크 사용

이 앱은 산업용 PLC(미쓰비시 MELSEC 계열)와 통신하는 도구입니다. 네트워크는 다음에만 사용합니다.

PLC 접속 — 사용자가 입력한 IP 주소와 포트로 접속해 MC 프로토콜로 디바이스 값을 읽고 씁니다. 이 통신은 사용자가 지정한 상대와만 이루어집니다.

PLC 검색 — 사용자가 검색 버튼을 눌렀을 때만, 기기가 접속해 있는 로컬 네트워크 대역의 주소에 사용자가 설정한 포트로 접속을 시도해 PLC 를 찾습니다. 산업 현장에서 PLC 의 IP 를 모를 때 쓰는 기능이며, 찾은 결과는 화면에 보여 줄 뿐 어디에도 저장하거나 전송하지 않습니다. 이 동작은 사용자가 직접 실행할 때만 일어납니다.

TCP 송수신(부가기능) — 사용자가 주소와 포트를 직접 넣고 접속 단추를 눌렀을 때만, 그 상대와 TCP 로 접속해 사용자가 적은 내용을 보내고 받은 것을 화면에 보여 줍니다. 로봇·비전 같은 장비의 통신을 확인하는 용도이며, 주소를 훑거나 장비를 찾아 주지 않습니다. 주고받은 기록은 창을 닫으면 사라지고 따로 저장하거나 다른 곳으로 전송하지 않습니다.

광고 수신 — 배너 광고를 받아 오기 위해 구글 광고 서버와 통신합니다.

앱이 통신하는 상대는 위 넷뿐이며, 개발자가 운영하는 서버는 없습니다. PLC 에서 읽은 값, 연 파일의 내용, 점검 기록은 광고 서버를 포함해 어디로도 전송되지 않습니다.

권한

앱이 직접 선언한 권한은 둘입니다.

권한사용 목적
INTERNET사용자가 지정한 PLC·장비와 TCP 통신, 광고 수신
ACCESS_NETWORK_STATEPLC 검색 시 기기가 붙어 있는 네트워크 대역 확인

나머지는 구글 광고 라이브러리가 자동으로 붙이는 것으로, 광고 표시와 측정에만 쓰입니다.

권한사용 목적
AD_ID광고 식별자 사용
ACCESS_ADSERVICES_AD_ID, ACCESS_ADSERVICES_ATTRIBUTION, ACCESS_ADSERVICES_TOPICS안드로이드 프라이버시 샌드박스를 통한 광고 측정
WAKE_LOCK, FOREGROUND_SERVICE광고 라이브러리 내부 처리

모두 사용자 승인이 필요 없는 일반 권한이며, 카메라·위치·연락처·저장소 같은 민감 권한은 하나도 요구하지 않습니다.

제3자 제공

개발자가 제3자에게 제공하는 데이터는 없습니다.

앱에 포함된 제3자 SDK 는 구글 애드몹(Google Mobile Ads SDK) 하나뿐이며, 그 처리 내용은 위 「광고」 절에 적었습니다. 분석 SDK 와 크래시 리포팅 도구는 포함하지 않았습니다.

데이터 삭제

  • 점검 기록만 지우려면 앱 안에서 관련 기록을 지우면 됩니다.
  • 저장된 모든 내용을 지우려면 기기 설정에서 앱 데이터를 삭제하거나 앱을 제거하면 됩니다.
  • 앱을 제거하면 앱이 저장한 내용은 기기에서 모두 사라집니다.
  • 광고 식별자는 앱이 아니라 기기가 가지고 있으므로, 위 「광고」 절의 방법으로 기기 설정에서 재설정하거나 삭제하십시오.

아동

이 앱은 산업 설비 정비를 위한 도구이며 아동을 대상으로 하지 않습니다. 만 14세 미만 아동에게서 의도적으로 정보를 수집하지 않습니다.

변경

이 방침이 바뀌면 이 문서의 최종 수정일을 갱신하고 앱 업데이트와 함께 알립니다.

문의

기능 요청, 버그 신고 및 개인정보 처리에 관한 문의는 아래로 연락 주십시오. 앱은 문의를 자동 전송하지 않으며, 사용자가 선택한 메일 앱에서 내용을 확인하고 직접 전송합니다. 수신한 이메일 주소와 문의 내용은 답변 및 앱 개선 목적으로만 사용하고, 문의 처리가 끝난 뒤 불필요해지면 삭제합니다. PLC IP, GXW, 코멘트 파일 등 업무상 민감한 자료는 자동 첨부하지 않으며 사용자가 직접 첨부한 자료만 수신합니다. 삭제를 원하는 경우 같은 주소로 요청할 수 있습니다.
