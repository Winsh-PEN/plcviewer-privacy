PLC 툴박스

래더 보기, 배선 점검, 실시간 값 확인. 설비 앞에서 노트북 없이 쓰는 도구

노트북을 펴지 않고도 래더 회로를 보고, 디바이스 코멘트를 찾고, PLC 에 직접 접속해 실제 값을 확인하면서 점검 결과를 기록할 수 있습니다. 미쓰비시 MELSEC 계열의 MC 프로토콜 3E 로 통신합니다.

메인 화면에서 래더 보기와 IO 체크로 갈라지고, PLC 없이 혼자 도는 계산 도구는 부가기능에 모여 있습니다.

주요 기능

래더 보기

프로젝트 파일(.gxw)이나 프로그램 CSV 를 열면 회로를 그려 줍니다. 접속해 두면 통하는 접점이 초록으로 칠해져, 출력이 왜 안 나오는지 설비 앞에서 짚을 수 있습니다.

통전 판단

b접점은 꺼져 있을 때 통한다는 것까지 반영합니다. 타이머·카운터는 현재값이 아니라 접점을 읽고, 비교 명령과 인덱스 수식도 판단합니다.

코멘트와 라벨 그대로 읽기

GX Works2 가 내보낸 코멘트 CSV 를 변환 없이 엽니다. UTF-16 탭 구분과 UTF-8 을 모두 인식하고, 프로젝트 파일 안의 코멘트와 라벨 이름도 직접 읽습니다.

실시간 값 확인

IP 와 포트를 넣으면 접속해 현재값을 계속 갱신합니다. 10진·16진·문자로 바꿔 볼 수 있고, 디바이스명을 넣으면 그 자리로 바로 갑니다.

배선 점검

센서를 가린 채 한 번, 치운 채 한 번. 두 번 되풀이하면 앱이 스스로 판정합니다. 다른 접점과 뒤바뀐 것까지 찾아 양쪽에 표시합니다.

입출력 관찰과 트리거 기록

설비가 도는 것을 지켜보며 어느 출력에 어느 입력이 반응하는지 반응률·지연시간과 함께 정리합니다. 정해 둔 접점이 바뀌는 순간만 기록해 둘 수도 있습니다.

점검 기록과 CSV 내보내기

행마다 정상 체크와 메모를 남기고, 디바이스·코멘트·현재값과 함께 CSV 로 뽑아 엑셀에서 정리합니다. NG 로 판정된 행만 따로 뽑을 수도 있습니다.

PLC 검색

IP 를 모를 때 같은 네트워크를 훑어 PLC 를 찾습니다. CPU 형명까지 확인해 다른 장비와 구분합니다.

워드 속 문자열과 비트

워드 하나에 두 글자씩 담긴 문자열을 이어 붙여 읽고 씁니다. 한글(CP949)도 됩니다. D100.0 처럼 워드 안의 비트도 하나씩 펼쳐 봅니다.

부가기능

PLC 에 붙지 않아도 쓰는 계산 도구입니다. 체크섬(BCC·합계·2의 보수·CRC-16), 서보 주소, 모터·전자기어, 이상코드 검색.

PLC 쪽 준비

앱이 값을 읽으려면 PLC 이더넷 모듈에 MC 프로토콜 오픈 설정이 되어 있어야 합니다. GX Works2 의 네트워크 파라미터 → 오픈 설정에서 한 채널을 TCP / MC 프로토콜 로 잡고 자국 포트 번호를 정한 뒤, 앱의 접속설정에 같은 IP 와 포트를 넣으면 됩니다.

포트는 GX Works2 에서 16진수로 입력하는 화면이 많습니다. 앱에는 10진수로 넣어야 합니다.

래더만 볼 때는 접속이 필요 없습니다. 통전 색을 켜려는 경우에만 붙이면 됩니다.

안전

이 앱에는 출력을 강제로 켜고 끄는 기능이 있습니다. Y 를 ON 하면 그 출력에 연결된 실린더·모터·밸브가 실제로 움직입니다. 그래서 기본은 잠겨 있고, 켤 때 경고 확인을 한 번 받습니다. 설비 안이나 가동 범위에 사람이 없는지 반드시 확인하고 사용하십시오.
